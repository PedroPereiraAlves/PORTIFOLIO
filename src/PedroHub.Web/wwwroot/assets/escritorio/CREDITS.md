# Créditos — assets do Escritório

Sprites e tiles do mapa são **gerados em runtime** pelo `escritorio.js` (Phaser Graphics → texturas 16×16).

Não há pacote externo de tileset neste PR. Se no futuro for adicionado um pack Kenney (Tiny Town / Roguelike Indoors), manter a licença CC0 do autor nesta pasta.

- Motor: [Phaser 3](https://phaser.io/) (MIT) — `wwwroot/lib/phaser/`
- Arte procedural: domínio público / uso livre no PedroHub
